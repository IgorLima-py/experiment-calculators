# Experiment Calculators

Free calculators for A/B testing and marketing experiments — sample size, minimum
detectable effect, peeking correction, geo-holdout power, and a CUPED explainer.
Every result comes with one plain-English sentence of judgement: what the number
means, and what would invalidate it.
